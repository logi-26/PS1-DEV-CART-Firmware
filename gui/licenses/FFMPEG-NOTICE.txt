PS1 Dev Cart Manager - FFmpeg and the libraries that come with it
=================================================================

What FFmpeg is
--------------
FFmpeg (https://ffmpeg.org) is a free, open source set of libraries that read and decode almost
every video and audio format (MP4, MKV, AVI, MP3, AAC, internet streams and many more).

What the Manager uses it for
----------------------------
The PS1 Dev Cart Manager executable contains PyAV (https://pyav.org), the Python binding of FFmpeg,
with FFmpeg's libraries. They are used only by these pages:
- Video streamer: decodes the video files and links you add, the Manager then converts the pictures
  to the PlayStation's MDEC format and the sound to PlayStation ADPCM, and streams them to the
  console;
- Audio streamer: decodes the audio files and the links that aren't plain MP3 radio streams (those
  are played with miniaudio).
Nothing is encoded with FFmpeg, and nothing else in the Manager, the firmware or ps1transfer uses
it. Running the Manager from its Python sources uses the PyAV/FFmpeg you install yourself
("pip install av").

Versions and licenses (as built by PyAV 18.1.0 for Windows)
-----------------------------------------------------------

  LGPL version 3 or later (FFmpeg reports "LGPL version 3 or later": built with --enable-version3).

Other libraries that PyAV's FFmpeg is built with (separate DLLs, loaded by FFmpeg):
  libx264, libx265 (H.264/H.265 encoders)  GPL version 2 or later, GPL-2.0.txt
  libmp3lame (MP3 encoder)                 LGPL version 2 or later, LGPL-2.1.txt
  libiconv                                 LGPL version 2.1 or later, LGPL-2.1.txt
  dav1d (AV1 decoder)                      BSD 2-Clause
  SVT-AV1 (AV1 encoder)                    BSD 3-Clause Clear (with the Alliance for Open Media patent license)
  libvpx (VP8/VP9)                         BSD 3-Clause
  Opus                                     BSD 3-Clause

The Manager doesn't use the encoders: they are only there because FFmpeg is built with them.

Source code
-----------
These libraries are used unmodified, as distributed in PyAV's wheel for Windows (pip install av==18.1.0).
The exact source code of the GPL and LGPL ones, as used for this build:
- x264 (commit b35605ac):
  https://code.videolan.org/videolan/x264/-/archive/b35605ace3ddf7c1a5d67a2eb553f034aef41d55/x264-b35605ace3ddf7c1a5d67a2eb553f034aef41d55.tar.bz2
- x265 4.2: https://bitbucket.org/multicoreware/x265_git/downloads/x265_4.2.tar.gz
- FFmpeg 8.1.2: https://ffmpeg.org/releases/ffmpeg-8.1.2.tar.xz
- LAME 3.100: http://deb.debian.org/debian/pool/main/l/lame/lame_3.100.orig.tar.gz
- GNU libiconv 1.19: https://ftp.gnu.org/pub/gnu/libiconv/libiconv-1.19.tar.gz (the Windows DLL comes from the

- How they were built (configure options, patches, SHA-256 of each archive above): PyAV's build scripts,
  https://github.com/PyAV-Org/pyav-ffmpeg/tree/8.1.2-1 (scripts/build-ffmpeg.py)
- PyAV: https://github.com/PyAV-Org/PyAV (release 18.1.0)

Replacing the libraries (LGPL)
------------------------------
You may replace FFmpeg's libraries with your own build of the same versions (or compatible ones):
run the Manager from its Python sources (gui/ps1devcart_gui.py) with your own PyAV/FFmpeg
installation, or rebuild the executable (gui/ps1devcart_gui.spec, PyInstaller) with them.
